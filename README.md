Змейка на Python

Автор: Вадим Гусейнов

О проекте.

Это классическая игра "Змейка", которую я написал на Python с использованием Pygame. Ты управляешь змейкой, которая ползает по экрану, ест красные яблоки и растет. Главное — не врезаться в собственный хвост, иначе игра начнется заново. 

В игре:

1. Змейка движется по сетке, управляется стрелками.
2. Яблоки появляются в случайных местах, но не на змейке.
3. Если врежешься в себя, змейка сбрасывается до начального состояния.

Запуск игры.

1. Проверить, что есть Python. Нужен Python 3.8 или новее. 
   Проверь версию командой в терминале: python --version

2. Установить Pygame:
   Установить можно ее через pip: pip install pygame

3. Скачать код:
   Клонировать репозиторий: git clone <ссылка_на_репозиторий>

4. Запустить игру:

   - Открыть терминал, перейти в папку с файлом:cd путь/к/папке
   - Запустить игру:python snake_game.py


Правила игры:

- Управлять змейкой нужно стрелками на клавиатуре.
- Есть яблоки, чтобы расти.
- Стараться не врезаться в себя.
